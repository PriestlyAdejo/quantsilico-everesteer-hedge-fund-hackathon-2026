## Before anything leaves the machine

The submission guard checks, where applicable:

- event identity;
- round;
- lane;
- split fingerprint;
- prediction ID coverage;
- duplicate IDs;
- prediction format;
- prediction artefact;
- model artefact;
- model loadability;
- event capability;
- remaining quota.

A red integrity failure blocks the external action.

## DRY_RUN

Use DRY_RUN while validating the system.

<Command>
.\.venv\Scripts\qseh.exe event submission-mode
</Command>

<Command>
.\.venv\Scripts\qseh.exe submit check
</Command>

## ARMED

Real uploads require explicit human intent.

<Command>
.\.venv\Scripts\qseh.exe event arm-submissions
</Command>

Do not arm until account, event and snapshot identity have been verified.

<Callout tone="danger">
Neither rehearsal nor autopilot may automatically transition the system to
ARMED.
</Callout>

## Idempotency

A restart must not submit the same action twice.

Submission history therefore records enough context to identify an equivalent
event/round/split/candidate/action combination.

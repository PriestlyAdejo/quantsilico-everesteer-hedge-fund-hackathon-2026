## Fit

`ExperimentRunner` reads YAML, fits through `create_model`, writes OOF
predictions, fold metrics, resource measurements and an immutable run manifest
under `runs/experiments/<run_id>/`. Failed runs keep their evidence.

Factories currently registered include ridge, random_forest, extra_trees,
xgboost, lgbm, reference_lgbm and shallow_mlp.

## Artefact

`ModelRegistry` stores the fitted object and training data hash when provided.
A later live infer must load that artefact rather than refitting from memory.

## Lineage

Record parent candidate and config delta when an operator changes
regularisation, features, recency, seed or ensemble membership. Experiments
that cannot explain what changed are not useful under a live clock.

## Inference and submit

Round-room inference uses the champion or an approved ensemble. Submission
guard then checks event, lane, IDs, artefacts and quota. Do not add
model-specific submission code.

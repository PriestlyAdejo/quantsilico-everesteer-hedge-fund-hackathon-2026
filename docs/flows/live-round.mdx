## What to watch

<MetricDefinition name="Time remaining">
The authoritative estimate of how long the current round remains open.
</MetricDefinition>

<MetricDefinition name="Split fingerprint">
The content identity of the live dataset currently being used for inference.
</MetricDefinition>

<MetricDefinition name="Inference ETA">
Whether the selected candidate will finish early enough to be useful.
</MetricDefinition>

<MetricDefinition name="Upload budget">
How many external submissions remain available.
</MetricDefinition>

## Normal path

The live-round controller should detect the event state and avoid repeated work
when the dataset fingerprint is unchanged.

The same round must not accidentally produce duplicate external uploads after a
restart.

## When a live result is poor

Do not immediately rewrite the model stack.

First determine whether:

- the correct split was submitted;
- IDs aligned;
- the correct lane was used;
- event scoring changed;
- data drifted;
- all models failed together;
- one model failed while others remained stable.

One noisy external round is evidence, not a command to discard all prior local
validation.

<Callout tone="warning">
Do not start an architectural refactor while a live round is closing.
</Callout>

## Start

<Command>
.\.venv\Scripts\qseh.exe dashboard diagnose
</Command>

<Command>
.\.venv\Scripts\qseh.exe dashboard start
</Command>

<Command>
.\.venv\Scripts\qseh.exe dashboard status
</Command>

<Command>
.\.venv\Scripts\qseh.exe dashboard open
</Command>

## Health

<Command>
Invoke-RestMethod http://127.0.0.1:8766/api/health | ConvertTo-Json -Depth 10
</Command>

## Rebuild frontend

<Command>
.\.venv\Scripts\qseh.exe dashboard build
</Command>

## Restart

<Command>
.\.venv\Scripts\qseh.exe dashboard stop
</Command>

<Command>
.\.venv\Scripts\qseh.exe dashboard start
</Command>

## Diagnose failure

<Command>
.\.venv\Scripts\qseh.exe dashboard diagnose
</Command>

## Stop

<Command>
.\.venv\Scripts\qseh.exe dashboard stop
</Command>

## Regenerate documentation

<Command>
.\.venv\Scripts\qseh.exe docs build
</Command>

<Callout tone="warning">

and .venv\Scripts\python.exe directly.
